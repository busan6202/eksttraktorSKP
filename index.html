Hemat Waktu Hingga 90%

Tidak perlu lagi mengklik kanan satu-satu pada puluhan foto dokumentasi P2K2 atau berkas bansos di Google Drive lalu memilih "Get Link". Cukup salin 1 link folder, semua link berkas keluar otomatis.

Cegah Error Tautan Terkunci (Permission Denied)

Seringkali atasan penilai kinerja menolak SKP karena file Google Drive masih berstatus "Restricted". Aplikasi ini otomatis memverifikasi dan mengubah tautan menjadi "Anyone with the link can view".

Hasil ekstraksi dapat diunduh dalam bentuk berkas Excel (.csv) berformat tabel rapi, lengkap dengan nama dokumen, ukuran berkas, kategori triwulan, dan tautan langsung untuk arsip satuan kerja.

Keamanan Data & Cara Penggunaan

100% Sangat Aman. Aplikasi ini tidak memerlukan kata sandi akun Google Anda. Ekstraktor bekerja murni berbasis URL publik / link berbagi folder yang Anda masukkan sendiri. Kami tidak menyimpan atau menyalin isi dokumen Anda ke server luar.
Cukup klik tombol "Salin Teks untuk e-Kinerja" pada aplikasi. Kemudian buka e-Kinerja BKN, masuk ke menu Pelaksanaan Kinerja > Bukti Dukung, lalu tempel (Paste) teks tersebut pada kolom nama dan URL bukti dukung Anda.
Untuk versi Pro, tidak ada batasan jumlah file (Unlimited). Anda bisa mengekstrak ratusan foto P2K2, berkas pdf scan surat tugas, maupun folder bertingkat (sub-folder) dalam satu kali proses.
